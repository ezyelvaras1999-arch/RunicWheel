# Pacote mínimo para compilar e testar

Esta pasta contém só o necessário para compilar a DLL desta prova e testar a instalação: a fonte principal, os headers incluídos por ela, os dois ficheiros `.inl`, o script de build, o workflow, o INI e as quatro texturas `.rwtx` que o plugin carrega ao lado da DLL. O workflow obtém separadamente a fonte SKSE LE 1.7.3 do site oficial.

Foram removidos testes, imagens de referência, rascunhos de arte, versões antigas, documentos de histórico e recursos de QA. Eles não são necessários para este build.

Segue `GITHUB-BUILD-PT.md` para enviar esta pasta para um repositório e descarregar o artifact compilado. `PREVIEW-PROBE.md` explica o teste dentro do Skyrim.
